{{end}} {{/* The coin modal's live updater, shared by every page that shows it. Why it polls at all: the balance lives on the controller, and the only thing that knows a coin went in is the NodeMCU. Polling /api/coin-status is the simplest way for the browser to learn about it. One second, not two. The customer is standing at the machine watching this dialog, so a two second delay reads as "nothing happened" and is the single most common complaint about a coin box. The request is a single indexed row read, and the poller only runs while the modal is actually open, so the load is a handful of queries per customer rather than a constant background poll. Robustness rules this script follows, all of which matter on a walled-garden connection that drops without warning: * a failed poll never blanks the screen, it just says so quietly; * a response for a stale page (the guest navigated back) is ignored; * polling is suspended when the tab is hidden and when the modal is closed, so a phone in a pocket is not talking to the controller; * the "Done paying" press stops polling before the navigation starts, so a response that arrives mid-flight cannot repaint the page underneath it; * every string is written through textContent, never innerHTML, so a value from the network can never become markup. */}} {{define "coinScript"}} {{end}}
