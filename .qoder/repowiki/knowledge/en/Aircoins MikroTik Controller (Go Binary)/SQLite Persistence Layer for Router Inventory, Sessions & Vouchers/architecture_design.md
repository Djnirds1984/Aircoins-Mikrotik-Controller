Single Go package `database` built around a central `DB` handle (in `database.go`) that owns the `*sql.DB` pool, an AES-GCM `secretBox` for at-rest router password encryption, and per-domain store factories (`Routers()`, `Sessions()`, `Vouchers()`, `Coins()`, `Rates()`). Each domain lives in its own file (`routers.go`, `sessions.go`, `vouchers.go`, `coins.go`, `rates.go`, `portal_settings.go`, `admin_users.go`, `admin_sessions.go`, `stats.go`, `voucher_code.go`) exposing a `XxxStore` struct with CRUD methods over raw SQL. Schema is defined as inline DDL constants and applied via a forward-only, versioned migration system in `migrations.go` backed by a `schema_migrations` table; new versions are appended to the `migrations` slice rather than edited. Secrets are handled separately in `secretbox.go` (AES-GCM sealed values prefixed with `v1:`) and key material is resolved from `Config.SecretKey`, the `AIRCOINS_SECRET_KEY` env var, or a generated 0600-permission file. Time is stored as UTC RFC3339 strings (`times.go`) so TEXT columns sort lexicographically. The package uses the pure-Go `modernc.org/sqlite` driver (no cgo) and configures WAL mode, foreign keys, and a small connection pool via DSN pragmas in `buildDSN`. Error wrapping goes through `wrapDBError` / `isUniqueViolation` helpers in `netaddr.go`-adjacent error helpers, surfacing a sentinel `ErrNotFound`.
