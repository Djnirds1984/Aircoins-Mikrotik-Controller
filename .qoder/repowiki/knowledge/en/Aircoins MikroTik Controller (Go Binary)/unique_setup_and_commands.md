Binary supports three entry modes: `aircoins-controller --version` (no DB/server), `aircoins-controller passwd [--user <name>] [--show]` (standalone operator credential management before the service runs), and the default server mode. Environment variables drive all runtime config (`ADDR`, `DB_PATH`, `SECRET_KEY_PATH`, `ADMIN_USER`, `ADMIN_PASSWORD`, `PORTAL_NAME`, `API_TIMEOUT`, `SECURE_COOKIES`, `COIN_NODE_TOKEN`, etc.). Deployment helpers live in the root: `install.sh` for systemd + capabilities, `start_demo.sh`, `run_demo.ps1`, `netstart.ps1`, `reset_demo.ps1`, `smoke_network.ps1`.
