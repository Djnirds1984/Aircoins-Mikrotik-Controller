The root package is the application bootstrap: `main.go` parses CLI subcommands (`--version`, `passwd`, default run), loads environment-driven configuration from `config.go`, opens the `database` package's SQLite connection, embeds the `templates/*.html` views via `//go:embed`, instantiates `handlers.New(db, tpl, cfg.Handler)`, and starts an `http.Server` whose routes are returned by `handlers.Routes()`. A background goroutine launched from `run()` drives `sweeper.go`'s `expirySweeper`, which periodically calls `db.Vouchers().SyncExpired` and `db.Coins().ExpireIdle` to mark expired vouchers and release idle piso-wifi coin balances. Cross-child wiring is minimal and explicit: children never import each other — only the root composes them, keeping `database` and `handlers` pure packages. Lifecycle is signal-aware (SIGINT/SIGTERM) with a 15-second graceful shutdown, and the operator account is bootstrapped once on first start so the panel is never exposed without credentials.
