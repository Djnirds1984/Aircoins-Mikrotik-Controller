## What system/approach is used

The project is a single-process Go binary (`main.go`) with no Makefile, Dockerfile, or CI pipeline. Build and deployment are driven by:

- `go.mod` / `go.sum` — module definition (`github.com/djnirds1984/aircoins-mikrotik-controller`, `go 1.26.5`) plus two direct dependencies: `modernc.org/sqlite` (pure-Go SQLite) and `github.com/go-routeros/routeros/v3`.
- `install.sh` — the canonical installer/deployer for Debian/Ubuntu/Armbian/Raspberry Pi OS. It installs OS packages, provisions a `go` toolchain if needed, cross-compiles the binary via `go build`, writes a systemd unit, configures ufw/iptables, and performs a health check.
- `start_demo.sh` — a local dev helper that builds into `/tmp/aircoins-demo.exe`, starts it with test env vars, and curls `/healthz`, `/network`, `/api/v1/routers`, and portal endpoints.
- A handful of PowerShell scripts at the repo root (`netstart.ps1`, `run_demo.ps1`, `smoke_network.ps1`, `reset_demo.ps1`) for Windows-side smoke tests against a live MikroTik.

There is no CI configuration, no release automation, no container image, and no cross-compilation matrix in this repository; `install.sh` detects the host CPU (`x86_64`, `aarch64`, `armv7l/armv6l`, `riscv64`) and builds natively for that architecture.

## Key files and packages

- `go.mod` — declares Go version floor and pinned dependencies.
- `install.sh` — end-to-end install/build/service script (~550 lines).
- `start_demo.sh` — interactive demo launcher.
- `scripts/aircoins-install-zerotier` — privileged helper installed under `/usr/local/sbin` and granted via a dedicated sudoers rule.
- `README.md` — documents the manual `go build -o /tmp/aircoins-controller .` flow and the environment variables consumed at runtime.

## Architecture and conventions

### Build flags

`install.sh` compiles with:

```bash
go build -trimpath -ldflags "-s -w -X main.version=${VERSION_STR}" -o "$INSTALL_DIR/$APP_NAME" .
CGO_ENABLED=0 GOFLAGS="-p=$BUILD_JOBS"
```

- `CGO_ENABLED=0` — produces a fully static binary (no libsqlite3 dependency); the pure-Go `modernc.org/sqlite` package is required for this.
- `-trimpath` — strips local filesystem paths from the binary.
- `-s -w` — strips debug info and DWARF.
- `-X main.version=…` — injects the build-time version string into `main.version`.
- Parallelism is set to `$NPROC` but capped to 2 when RAM < 1 GiB.

### Versioning

Version resolution order (in `install.sh`):

1. `AIRCOINS_VERSION` environment variable (intended for releases).
2. `git describe --tags --always --dirty` on the source tree.
3. Literal `dev`.

The value is sanitized through `tr -c 'A-Za-z0-9._+-' '-'` before being passed as an `-ldflags` token, because the linker rejects spaces.

### Toolchain provisioning

`install.sh` enforces a minimum Go version derived from `go.mod`:

- Defaults to `MIN_GO_MAJOR=1`, `MIN_GO_MINOR=23`, `DEFAULT_GO_VERSION=1.23.5`.
- If `go.mod` requests a newer `go X.Y.Z`, the minimum and tarball version are raised to match.
- Prefers distro `golang-go`; falls back to downloading the official tarball from `${GO_MIRROR:-https://go.dev/dl}` and verifying its `.sha256` when available.
- Caches are exported as `GOCACHE=/root/.cache/go-build`, `GOMODCACHE=/root/go/pkg/mod`.

### Deployment layout

| Path | Purpose |
|---|---|
| `/opt/aircoins` | Install directory (binary lives here) |
| `/var/lib/aircoins` | Data directory (`aircoins.db`, `secret.key`) owned by service user |
| `/etc/aircoins/aircoins.env` | Environment file consumed by systemd `EnvironmentFile=` |
| `/etc/systemd/system/aircoins.service` | Systemd unit generated by the installer |
| `/usr/local/sbin/aircoins-install-zerotier` | Restricted root helper |
| `/etc/sudoers.d/aircoins-tools` | Sudoers rule granting the service user passwordless sudo for the helper only |

### Service model

- User/group `aircoins` (system account, no login shell).
- Port 80 binding is achieved via `AmbientCapabilities=CAP_NET_BIND_SERVICE` rather than running as root.
- `ProtectHome=true`, `PrivateTmp=true`, `ReadWritePaths=/var/lib/aircoins` restrict filesystem access.
- `NoNewPrivileges=false` is intentionally left unset so the helper can still acquire `CAP_SETUID/CAP_SETGID` via sudo.
- The unit reads `ADDR`, `DB_PATH`, `SECRET_KEY_PATH`, `PORTAL_NAME`, `ADMIN_USER`, `ADMIN_PASSWORD`, `API_TIMEOUT`, `SECURE_COOKIES`, `ADMIN_PATH`, etc. from `/etc/aircoins/aircoins.env`.

### Hardware detection

The installer auto-detects:

- CPU arch → Go `GOARCH` mapping (`x86_64/amd64`, `aarch64/arm64`, `armv7l/armv6l/arm`, `riscv64`).
- Board model from `/proc/device-tree/model` or `/sys/firmware/devicetree/base/model` (used for logging).
- Armbian vs generic Debian/Ubuntu via `/etc/os-release`.
- Available RAM; creates a 1 GB swap file when ≤ 1 GiB and none exists.

### Firewall

If `ufw` is active, opens the controller port (and SSH on first enable). Falls back to raw `iptables` rules otherwise. `--skip-firewall` disables this step.

### Health verification

After enabling/restarting the service, the installer polls `http://<addr>/healthz` up to 30 times (1 s apart) and fails the install if the response does not contain `ok`. This guards against migrations/password derivation taking longer than expected on low-power boards.

## Conventions and constraints

- **Pure-Go build**: `CGO_ENABLED=0` is enforced by the installer; the presence of `modernc.org/sqlite` in `go.mod` is checked and warned about if missing. No external `libsqlite3` is linked.
- **Go version floor**: `go.mod`'s `go X.Y.Z` line raises the minimum enforced by `install.sh`; the script refuses to proceed without a Go toolchain meeting that floor.
- **Idempotent install**: Re-running `install.sh` upgrades the binary in place, preserves `/etc/aircoins/aircoins.env` (except migrating the legacy default `ADDR=0.0.0.0:8080`), and restarts the service so the newly built binary takes effect.
- **Binary name**: always `aircoins-controller` (constant `APP_NAME`).
- **Service name**: always `aircoins` (constant `SERVICE_NAME`).
- **Port validation**: `--port` must be numeric and in `1..65535`; the effective port is re-extracted from `ADDR` in the env file after install.
- **Privilege boundary**: the controller runs as unprivileged user `aircoins`; only the one argument-less helper `/usr/local/sbin/aircoins-install-zerotier` is allowed via sudoers, and the systemd unit explicitly avoids setting `CapabilityBoundingSet=` so that helper can still escalate.
- **Build reproducibility**: `-trimpath` removes source paths; version is injected via `-ldflags -X main.version=…` and sanitized to ldflags-safe characters.
- **Demo workflow**: `start_demo.sh` expects `go` on PATH, builds to `/tmp/aircoins-demo.exe`, then sets `ADDR=127.0.0.1:19111 DB_PATH=/tmp/aircoins-demo.db API_TIMEOUT=4s SECRET_KEY_PATH=/tmp/aircoins-demo.key` and verifies `/healthz` plus several network/portal endpoints.
